# Urdu terminology (UI translation)

The Urdu interface uses formal Urdu as written in Pakistani courts and court notices, not word-for-word
translation. Every Urdu string in `frontend/src/locales/ur/` follows this table, so one concept always has one word.

Rules
- Technical identifiers stay as they are, left to right: UCN, CNIC, PKR, PDF, GPS, case numbers
  (`DA-2026-CIV-000001`), challan, receipt and certificate numbers, phone numbers, emails and dates (DD-MM-YYYY).
- Numbers use Western digits (0-9).
- The brand is written "ڈیجیٹل عدالت" in Urdu text and "DigitalAdaalat" in the wordmark.
- Buttons use the polite imperative ("محفوظ کریں", "دائر کریں"); messages use complete sentences ending in "۔".
- Generated PDFs (receipts, reports, certificates, proofs of service) stay in English.
